# Student Score Predictor

A web-based application built with Flask and Python that predicts student performance or exam scores based on various input parameters.

## Features
- Interactive user interface to input student metrics.
- Backend powered by Python and Flask.
- Real-time score prediction results.

## Getting Started

### Prerequisites
Make sure you have Python installed, then install the required dependencies:
```bash
pip install flask

python -m flask --app backend/app.py run --host 0.0.0.0 --port 5000
